One joke about office life, one line, written to make the AI judge laugh.

`main.ts` (Node 22, no dependencies) writes the joke to `/output/entry.txt`,
checking the house gate first: 1–200 characters, not whitespace-only.
The joke is a hand-written constant — no network, no randomness — so every
run produces the same bytes.

Run it with:

```sh
node main.ts
```
